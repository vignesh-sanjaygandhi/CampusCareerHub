\# CampusCareer Hub 🎓



A full-stack web application designed to streamline student placements. It acts as a career management platform where students can view available job postings and receive automated job recommendations based on their technical skills.



\## 🚀 Features

\* \*\*Rule-Based Matcher:\*\* An algorithm that calculates a match percentage by comparing a student's inputted skills against required job qualifications.

\* \*\*RESTful API Backend:\*\* Built with ASP.NET Core to handle data retrieval, CORS policies, and recommendation logic.

\* \*\*Responsive Frontend:\*\* A modern, single-page application (SPA) built with React and Vite for instant data rendering and state management.

\* \*\*Lightweight Database:\*\* Uses SQLite and ADO.NET for efficient, serverless local data storage.



\## 💻 Tech Stack

\* \*\*Frontend:\*\* React.js, Vite, HTML5, CSS3

\* \*\*Backend:\*\* C#, ASP.NET Core Web API

\* \*\*Database:\*\* SQLite, ADO.NET Architecture
